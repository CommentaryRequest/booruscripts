# booru scripts

Userscripts for danbooru (of varying usefulness)

## [Absolute Time](https://github.com/CommentaryRequest/booruscripts/blob/main/absolutetime.user.js)

Append absolute timestamp to all relative timestamps (such as "6 hours ago").

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/absolutetime.user.js)

## [Alternate Feedback Display](https://github.com/CommentaryRequest/booruscripts/blob/main/altfeedback.user.js)

Show user feedback as green, yellow and red numbers instead of `positive:# neutral:# negative:#`

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/altfeedback.user.js)

## [Commentaries Link in Sidebar](https://github.com/CommentaryRequest/booruscripts/blob/main/commentarylink.user.js)

Adds a "Commentaries" link in the sidebar on post list page in the "Related" section to quickly view commentaries under a specific search.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/commentarylink.user.js)

## [Expand Post Counts](https://github.com/CommentaryRequest/booruscripts/blob/main/expandpostcounts.user.js)

Replaces abbreviated post counts in tag lists with their full count.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/expandpostcounts.user.js)

## [Custom Tag Count](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/customtagcount.user.js)

Adds a custom, colored tag count above the tag list.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/customtagcount.user.js)

## [Favorite on Upload Page](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/favuploadpage.user.js)

Adds `fav:Username` into the tag list on upload, unless your name is RommentaryCequest.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/favuploadpage.user.js)

## [Mod Queue Utils](github.com/CommentaryRequest/booruscripts/blob/main/modqueueutils.user.js)

Adds various utilities to the moderation queue:

* Adds a button to quickly check if the artist tag is present on a post and whether it has any AI-generated or AI-assisted tagged posts.
* Shortcuts: Q to focus search bar in modqueue page, M to open modqueue from posts page
* Adds a SFW modqueue link (for checking the queue in public, possibly)
* Adds a toggle for default modqueue view mode: list or grid
* Adds a total post count in the modqueue page
* Highlight more tags, such as `third-party_source`, `official_art`, `game_asset`, `cropped`, etc.
* Moves the search bar and sidebar to the top of the page on mobile

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/modqueueutils.user.js)

## [Pool Order on Post Page](https://github.com/CommentaryRequest/booruscripts/blob/main/poolorder.user.js)

Adds a link to quickly order posts in pools that the post is a part of. Useful when uploading a large pooled series out of order.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/poolorder.user.js)

## [Animated GIF Thumbnails](https://github.com/CommentaryRequest/booruscripts/blob/main/postlistgif.user.js)

Changes thumbnails of GIF posts to an animated image instead of a static thumbnail.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/postlistgif.user.js)

## [Prevent Leaving Upload Page](https://github.com/CommentaryRequest/booruscripts/blob/main/preventleave.user.js)

Prevents accidentally leaving the upload page if you have entered any tags.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/preventleave.user.js)

## [Safe Mode Switch](https://github.com/CommentaryRequest/booruscripts/blob/main/safemodeswitch.user.js)

Adds a button in the lower-right of the screen to quickly switch safe mode on and off.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/safemodeswitch.user.js)

## [Tag Script Dropdown](https://github.com/CommentaryRequest/booruscripts/blob/main/tagscriptdropdown.user.js)

Adds a dropdown to allow switching between tag scripts on mobile.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/tagscriptdropdown.user.js)

## [Tag Timer](https://github.com/CommentaryRequest/booruscripts/blob/main/tagtimer.user.js)

Records how long it takes to tag posts, with statistics viewable on your profile page.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/tagtimer.user.js)

## [Topic and Pool Helper](https://github.com/CommentaryRequest/booruscripts/blob/main/topicpoolhelper.user.js)

Shows topic and pool names in dtext links. (e.g. `topic #7713` becomes `topic #7713 (Artist alias request thread)`)

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/topicpoolhelper.user.js)

## [Mode Menu Shortcuts](https://github.com/CommentaryRequest/booruscripts/blob/main/modemenushortcuts.user.js)

Adds customizable keyboard shortcuts for quickly switching between the modes in the mode menu.

* [Install](https://github.com/CommentaryRequest/booruscripts/raw/refs/heads/main/modemenushortcuts.user.js)
